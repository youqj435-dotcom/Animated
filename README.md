# Animated

Minimalist utility client for Minecraft Java Edition 1.21.1 with Fabric Loader.

## Features
- Module system with Combat, Movement, Player, Render, Legit and Misc categories
- Legit NoRender to suppress fire, fog and particle noise
- Combat modules like KillAura and Velocity with target selection filters
- Bridge-style HUD with placement stats and blocks-per-second tracking
- Modern ClickGUI with dark minimal panels
- Alpha PNG texture support for branded assets
- Subtle UI audio feedback for hover and click interactions
- Loading screen hook ready for custom splash branding

## Requirements
- Java 21
- Fabric Loader for Minecraft 1.21.1
- Gradle 8.12+

## Build
```bash
./gradlew build
```

## Run in dev
```bash
./gradlew runClient
```
